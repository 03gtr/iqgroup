# IQ Group — XPS Rebuild

Mobile-first single-page digital business card / XPS experience for IQ Group.

## Flow
1. QR opens the page.
2. Cinematic boot screen.
3. IQ Group identity card enters automatically — no tap required.
4. Identity confirmation reveals contact links.
5. Scroll to the services / work section.
6. English or Arabic is selected automatically from browser language, with manual EN / ع switch.

## Language override
- `?lang=en`
- `?lang=ar`
