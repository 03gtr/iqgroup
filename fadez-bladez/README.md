# Fadez & Bladez — One Page Website

A lightweight, mobile-first static landing page concept for Fadez & Bladez Barbershop, Riverwood NSW.

## Files
- `index.html` — page structure/content
- `styles.css` — responsive design + animations
- `script.js` — scroll reveal + subtle hero motion
- `assets/logo-concept.svg` — cleaned logo concept
- `assets/logo-original.jpg` — original supplied logo
